# Replication materials for: Cahn, Y. (2026) "Generalized Fiducial Inference Through Stochastic Inversion of Estimating Equations"

## Requirements

R version 4.5 or later

Required packages:

- MASS
- ggplot2

## Reproducing Results

Run

source("CGFI.R")

This reproduces all simulation results and figures in the paper.
